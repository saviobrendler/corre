# Corre

Simulador de vida no estilo BitLife, em português: uma vida inteira, um ano por toque, em 50 países com leis, escolas, universidades, carreiras e moeda próprios.

## Como rodar

É um site estático, sem build. Abra `index.html` no navegador ou publique a pasta como está (Vercel, Netlify, GitHub Pages).

## Arquivos

| Arquivo | O que tem |
|---|---|
| `index.html` | Marcação e estilos |
| `js/eventos.js` | Cartas de evento |
| `js/paises.js` | Moedas, câmbio e nomes por cultura |
| `js/perfis.js` | Os 50 países jogáveis: leis, escola, universidades, polícia, política, realeza, ligas e cotidiano |
| `js/jogo.js` | Motor e interface |
| `js/sistemas.js` | Fama e seguidores, golpes de luta, fuga do flagrante e atividades extracurriculares |
| `js/mundo.js` | Liga cada país ao jogo |

O histórico de mudanças está em [MUDANCAS.md](MUDANCAS.md).
